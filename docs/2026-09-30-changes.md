# 2026-09-30 변경 노트

마지막 커밋 이후 누적된 미커밋 변경과 오늘 적용한 작품 입력 UI 개선을 함께 정리한다.

## 작품 입력 UI

- 상단과 목록 하단에 작품 추가 버튼을 제공한다.
- 새 작품을 마지막 순서에 추가하고, 해당 폼으로 자동 스크롤한 뒤 첫 입력란에 포커스를 둔다. 모션 감소 설정에서는 즉시 이동한다.
- 한 작품의 편집 폼만 펼치고, 나머지는 썸네일·작품명·작가 요약으로 표시한다. 접기와 펼치기 사이에 입력값을 유지한다.
- 작품 삭제 시 펼쳐진 작품의 위치를 보정한다. 이미지 업로드 중에는 추가·삭제를 막는다.

## PDF 가져오기

- PDF 허용 용량을 20MB에서 100MB로 늘리고, 브라우저·서버 설정·안내 문구를 맞춘다.
- 업로드 용량 초과와 로그인 만료 오류를 이해하기 쉬운 메시지로 반환한다.
- 페이지·줄 경계를 보존하는 `PdfTextDocument`와 작품 전용 `PdfArtworkParser`를 도입한다.
- 작가 소개와 뒤따르는 작품 캡션 연결, 여러 줄 재료, 가격·통화·On Hold, 프레임·에디션·가변크기 처리를 개선한다. 동명 작품을 별도 작품으로 유지한다.
- ThisWeekendRoom 및 ARARIO 실제 카탈로그의 이미지·메타데이터를 제거한 테스트 사본을 추가한다. 두 문서 각각 34개 캡션과 작품 순서·작가 구간을 회귀 검증한다.
- OCR·PDF 이미지 추출·다단 좌표 해석은 지원하지 않는다. 상세 내용은 [PDF 가져오기 노트](pdf-import.md)에 기록한다.

## 작품 이미지 업로드 및 보관

- 이미지 URL 입력과 함께 JPEG·PNG 파일 업로드를 지원한다. 최대 10MB·2,400만 픽셀을 검사하고 재인코딩해 메타데이터를 제거한다.
- 로컬 비공개 저장소와 선택 가능한 Supabase 비공개 버킷 저장소를 추가한다.
- 이미지 소유권과 컨텐츠 참조를 DB에 기록한다. 수신자별 작품 스냅샷에서도 이미지 참조를 유지한다.
- 소유자 또는 패스키 인증 후 발급된 세션 권한으로 이미지를 읽는다. 수신자 권한은 30분이며 링크 만료·수신자 철회를 다시 확인한다.
- 참조되지 않은 업로드는 24시간 이후 정리 대상으로 삼고, 매시간 정리한다.
- 설정 예시와 저장소 운영 방법은 [이미지 보관 문서](content-images.md)에 기록한다. 로컬 이미지 데이터와 원본 테스트 PDF는 Git에서 제외한다.

## 검증

- 프론트엔드 `npm run build`: 통과. 500kB 초과 JS 번들 경고가 남아 있다.
- `git diff --check`: 통과.
- 전체 Java 테스트 `./mvnw -q test`: 173개 실행, 실패 0·오류 3·건너뜀 0. `ContentPersistenceTest` 3개는 샌드박스에서 Mockito의 JVM self-attach가 차단되어 오류가 발생했다. 샌드박스 밖 재실행 요청은 중단되어 전체 통과를 확인하지 못했다.
- 작품 입력 UI의 브라우저 자동 검증은 Playwright 브라우저 실행 파일 부재와 로컬 서버 실행 제한으로 완료하지 못했다.
- 이 작업은 변경 기록·커밋·푸시이며 운영 배포나 기존 컨텐츠 재파싱은 포함하지 않는다.
